# Встречи и интервью — публичный протокол хранения

**Оригинальные записи встреч не добавлять в публичный репозиторий.** Здесь только инструкция и шаблон. Исходные заметки, номера телефонов, контакты, внутренние документы хранятся в отдельном закрытом Obsidian Vault с ограничением доступа.

Процесс: сырой протокол → отделение прямой речи от толкования → список тезисов с метками `interview_unverified` → вопросы на проверку → публично допустимые выводы с источниками → решение команды.

Запрещено: «официально установленный факт» из слов одного участника встречи; автоматическая публикация имен/контактов; переименование спорной гипотезы в норматив; автоматическая отправка текста интервью в Codex, работающий в общедоступном контексте.

Используйте [шаблон](../templates/MEETING_NOTE.md) и [правила достоверности](../research/EVIDENCE_RULES.md).
