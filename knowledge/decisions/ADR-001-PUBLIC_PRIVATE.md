# ADR-001 — разделить публичную техническую базу и закрытые материалы

- Дата: 2026-11-20
- Статус: принято в организационном плане; применять при подготовке PR
- Контекст: GitHub-репозиторий `rust08/Sever-GitHub` **публичный**; обсуждения с практиками могут содержать не предназначенные для публикации детали.
- Решение: `knowledge/` содержит публично допустимые инструкции, схемы, проектные гипотезы и ссылки на открытые источники. Полные тексты интервью, контакты и непубличные документы хранить в отдельном Vault **вне GitHub**.
- Последствия: Codex по умолчанию видит только общую базу; для приватной задачи предоставлять разрешённый фрагмент в контролируемой рабочей сессии.
- Альтернатива: сделать репозиторий приватным и разграничить доступ; отдельное решение команды.
