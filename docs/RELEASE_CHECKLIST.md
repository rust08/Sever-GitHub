# Демонстрационный релиз и перенос

- Node 24. Локальные проверки: npm test, npm run build, npm run demo. Отдельный браузерный прогон на 390 × 844 охватил все экраны в двух темах. [Проверка функций и снимки](../research/DASHBOARD_QA.md).
- Для демонстрации полного процесса используйте локальный сервер. Облачная сборка рассчитывает сценарий без записи общей смены. В автономном HTML доступны локальные карта и планировщик.
- Учебные допуски и сценарные тарифы требуют первичных документов и технической проверки перед эксплуатацией.
- Исходники поставляются с картой, исследованиями и атрибуцией. Рабочие базы, ключи и настройки пользователя отсутствуют в архиве исходников, сформированном из Git.
- При переносе в новый репозиторий распакуйте архив исходников в отдельную ветку. Если репозиторий мероприятия уже содержит другие проекты, поместите Север в свою папку. В этом случае workflow нужно разместить в корневой .github/workflows и указать рабочую папку для команд и путь артефакта.
- Для собственного облачного развёртывания настройте идентификатор проекта в .openai/hosting.json. Для локального запуска и HTML этот идентификатор не нужен.
- До передачи проверьте требования мероприятия к лицензии и сторонним материалам. Лицензии картографических источников и Leaflet сохранены. Общую лицензию на авторский код определяет команда.
