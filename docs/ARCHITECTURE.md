# Как устроен Север

| Каталог | Ответственность |
|---|---|
| public/ | Шесть экранов диспетчерской, редактор парка, карта Leaflet и локальная подложка |
| backend/ | Проверка входов, правила приоритета, планировщик, вывоз, общее расписание, учебные наряды |
| data/ | Версионные снимки сети, источники и условия использования |
| drizzle/ | Последовательные миграции SQLite, применяемые локальным сервером |
| tools/ | Импорт и отрисовка данных, сравнение стратегий и сборка автономного HTML |
| knowledge/, research/ | Решения команды, исследования, ограничения и история этапов |

**План.** Форма передаёт параметры смены в service.mjs. policy.mjs формирует направленные проходы. planner.mjs распределяет их по технике с учётом возврата на базу. unified-shift.mjs объединяет результат с haul.mjs и проверяет пересечения интервалов и деньги.

**Исполнение.** server.mjs обслуживает локальный интерфейс и открывает SQLite. registry.mjs хранит редакции оснований, execution-journal.mjs записывает переходы состояний. demo-shifts.mjs хранит отдельные снимки сценария снегопада. Действия ролей учебные.

**Поставка.** Автономный HTML включает карту и вычислительный Web Worker. Облачный модуль собирается в dist/server/. Рабочие базы и результаты сборки создаются на машине пользователя.
