# Источник районной сети для регрессионных тестов

Для основной карты и городского планировщика см. [источники данных по всему округу](CITY_SOURCES.md).

Координаты, названия, направления, геометрия участков, класс дороги и сведения о прохождении автобусных маршрутов получены из [OpenStreetMap](https://www.openstreetmap.org/copyright), лицензия ODbL. Срез ограничен частью Петропавловска-Камчатского. Ограничивающий прямоугольник в порядке запад, юг, восток, север: 158.625, 53.038, 158.658, 53.057.

Чтобы воспроизвести импорт, скачайте [OSM XML](https://api.openstreetmap.org/api/0.6/map?bbox=158.625,53.038,158.658,53.057), сохраните под именем district.osm и выполните в каталоге проекта:

```sh
python tools/import_osm.py district.osm data/network.json
```

Требуется Python 3.10 или новее. Операционный сервер использует готовый снимок. Генератор оставляет пересечения внутри области, дробит дороги в общих узлах и сохраняет ломаную каждого участка. Уличные тупики с двусторонним движением сохраняются. Выбрана крупнейшая сильно связная компонента, поэтому при открытых дорогах достижим возврат к базе. Длина вычислена по всем вершинам сферической формулой, единицы — километры. В координатах первым идёт долгота. Время сборки записано в generatedUtc.

osmWay — идентификатор исходной линии, highway — класс OSM, oneway — направление от from к to, busRoutes — номера маршрутов, чьи отношения route=bus в выгрузке содержат исходную линию, bridge — тег моста. Пустой список автобусов означает отсутствие подтверждения в выгрузке. Остановка рядом с дорогой сама по себе не считается подтверждением. База обозначает условную отправную точку. Правила поворотов, ширина, полосность, уклон и текущая проходимость требуют дополнительных данных. Для допуска реальной техники нужно сверить эти условия и права проезда с оператором. Обязательные подъезды к медицинским и пожарным учреждениям подтверждает заказчик.
