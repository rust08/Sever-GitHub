# Показ диспетчерской

Запуск на Node 24+: npm start. Открыть адрес из терминала. Автономный HTML собирается командой npm run demo.

| Раздел | Сохранённые элементы и проверка |
|---|---|
| Обзор | #metrics, #shift-map, #minute. Выберите слой, машину и время, откройте участок. |
| План смены | #settings, #shift-details. Измените бюджет, задайте перекрытие, пересчитайте и откройте причину пропуска. |
| Техника | #fleet, #add-vehicle. Найдите машину, измените массу, сохраните карточку и пересчитайте смену. |
| Снеговывоз | #haul-form, #haul-result. Выберите точки на карте, сравните рейсы и общий бюджет. |
| Наряды | #order-panel, #journal-workflow. Создайте наряд, смените демо-роль и пройдите до решения заказчика. |
| Реестры | #registry-panel, #fleet-evidence. Откройте редакцию и источник сведений о машине. |

За 3 минуты: откройте Обзор, выберите участок, передвиньте время и покажите причину неназначения в плане. Переключите тему и вернитесь на карту.

За 5–7 минут: измените машину в парке, рассчитайте смену, откройте этап маршрута на карте. Создайте наряд по назначенному проходу. Покажите отдельные действия исполнителя, инспектора и заказчика. В плане запустите пример снегопада, сравните редакции и скачайте JSON.

В браузере проверены парк из 24 машин, сохранение массы, фильтры, учебная приёмка, реестр, повторный снегопад и экспорт. Общий расчёт проверен также в автономном HTML. Снимки шести экранов в обеих темах находятся в dashboard-qa/. После коррекции при 390 × 844 проверены все шесть экранов в обеих темах. Карта шириной 349 px, горизонтального переполнения страницы и ошибок JavaScript в прогоне не обнаружено. Журнал SQLite и редакции доступны на локальном сервере. Все тарифы и действия ролей учебные.
